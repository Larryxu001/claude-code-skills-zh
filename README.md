## 📖 What Are Claude Code Skills?

Claude Code Skills are reusable instruction modules that give Claude Code domain-specific expertise. A single `SKILL.md` file can turn Claude into a code-review expert, security auditor, documentation writer, and more.

### ⚡ Get Started in 30 Seconds

If you would rather not choose, install these five first:
- `zh-code-reviewer`
- `zh-readme`
- `api-tester`
- `refactor-advisor`
- `perf-profiler`

**Installation:** Copy the skill directory into `~/.claude/skills/`.

```bash
# Direct GitHub URL
git clone https://github.com/laolaoshiren/claude-code-skills-zh.git
cp -r claude-code-skills-zh/skills/* ~/.claude/skills/

# Mirror for users in China (use if GitHub is difficult to access)
git clone https://gh-proxy.com/https://github.com/laolaoshiren/claude-code-skills-zh.git
cp -r claude-code-skills-zh/skills/* ~/.claude/skills/

# Or download a ZIP directly (no git required)
# Direct GitHub: https://github.com/laolaoshiren/claude-code-skills-zh/archive/main.zip
# Mirror for users in China: https://gh-proxy.com/https://github.com/laolaoshiren/claude-code-skills-zh/archive/main.zip
```

## 🚀 How to Create Your Own Skill

Each skill is a directory containing a `SKILL.md` file:

```markdown
---
name: my-skill
description: A one-sentence description of the skill
---

# Skill Name

## Activation Conditions
Activate this skill when the user requests XXX

## Workflow
1. First step...
2. Second step...

## Output Format
- Format description...
```

### Skill Best Practices

1. **Make activation conditions clear** — Avoid conflicts with other skills
2. **Use concrete steps** — Tell Claude exactly what to do
3. **Include examples** — Provide sample inputs and outputs
4. **Keep it focused** — One skill, one job
5. **Combine Chinese and English** — Keep technical terms in English and write explanations in Chinese
